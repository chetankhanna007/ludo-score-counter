# Ludo Score Counter 🎲

A **React.js** score counter app for Ludo game, built with Vite. Tracks scores for multiple players with increment/decrement controls.

## 🛠️ Tech Stack
- React.js (Hooks — useState)
- Vite
- CSS3

## 🎯 Features
- Track scores for multiple players
- Increment and decrement controls
- Reset functionality

## 🔧 Setup & Run
```bash
npm install
npm run dev
```
